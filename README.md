# Pratyush & Minakshi Wedding Invitation

Responsive static wedding invitation website with the sage, ivory and champagne-gold colour palette.

## Preview
Open `index.html` in a browser. For the best experience, upload the contents of this folder to Netlify.

## Included
- Responsive invitation opening screen
- Wedding and reception details with venue map links
- Love-story section and invitation video
- Gallery, countdown and footer
- Local assets bundled in `assets/`

Palette: sage `#526B59`, warm ivory `#F9F5EC`, soft sage `#DDE5D7`, champagne gold `#B69A62`, deep sage `#284438`.
